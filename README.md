# Ondřej Schwarz — KISK Portfolio

Personal and academic portfolio built for Master's studies at **KISK MUNI** (*Design informačních služeb*, 2026–2028).

- **Live content language:** Czech
- **Code & documentation language:** English
- **Stack:** Astro 5, Tailwind CSS v4, `@lucide/astro`, Content Collections, Sharp image optimization, Netlify
- **Repository:** https://github.com/ondrulin/KISK-portfolio

## Quickstart

```bash
npm install
npm run dev
```

## Key Documentation

- [`AGENTS.md`](AGENTS.md) — Core rules, structure, semester workflow, and AI agent guidelines
- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) — Technical stack, routing, 3G performance, and Netlify deploy
- [`docs/DESIGN_SYSTEM.md`](docs/DESIGN_SYSTEM.md) — Colors, typography, layout widths, and disabled states
- [`docs/CONTENT_GUIDE.md`](docs/CONTENT_GUIDE.md) — Step-by-step guide for adding reflections, activating semesters, and optimizing images

## Scripts

npm run dev       # Local dev server
